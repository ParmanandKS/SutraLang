# 📸 SutraLang IDE - App Preview

Welcome to the visual tour of **SutraLang IDE**. Below you can see the core features and the modern **Glassmorphism** interface in action.

---

## 🚀 Key Screens

### 1. Splash Screen
A clean and professional entry point into the SutraLang ecosystem.
> ![Splash Screen](https://raw.githubusercontent.com/ParmanandKS/SutraLang/main/previews/splash.png)

### 2. The Smart Editor
The heart of the IDE. Features include:
*   **Real-time Output**: See results instantly.
*   **Theme Toggle**: Switch between Day and Night modes with a smooth rotation animation.
*   **Zoom Controls**: Adjust font size for better readability.
*   **Code Templates**: Quick-insert Hinglish syntax from the sidebar.

> ![Main Editor](https://raw.githubusercontent.com/ParmanandKS/SutraLang/main/previews/editor.png)

### 3. Navigation & Templates
Easy access to documentation and code snippets to speed up your development.
> ![Navigation Drawer](https://raw.githubusercontent.com/ParmanandKS/SutraLang/main/previews/drawer.png)

### 4. File Manager
Manage your `.sutra` files efficiently with our built-in explorer.
> ![File Manager](https://raw.githubusercontent.com/ParmanandKS/SutraLang/main/previews/files.png)
